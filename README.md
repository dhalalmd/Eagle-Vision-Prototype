# Eagle-Vision-Prototype
Modular smart border CCTV surveillance prototype (SIH26187). Live multi-camera feeds on a command-center dashboard, with pluggable AI features you can enable or disable.

# Smart Border CCTV Surveillance System

Prototype for Smart India Hackathon problem statement **SIH26187**.

## What it does
- Shows live feeds from multiple cameras (laptop webcam, phone camera) on one command-center dashboard
- Add, delete and manage cameras from the dashboard
- Modular design: each feature is a separate module that can be switched on or off
